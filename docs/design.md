# Interface direction

This is a utility workspace. Its question is: “What will move from my Anytype export into Anchor?”

The data: exported notes, task completion, object types, tag names, dates, file references, selected objects, unsupported blocks, conversion warnings. Empty counts are zero. Sample content appears only after choosing “Try an example”. No uploaded content leaves the browser or enters browser storage.

Dealt direction: **Framed sheet**, seed **69558703**. Chosen for a short, deliberate file conversion session. IBM Plex Sans is bundled locally. Palette: blue-grey ground #f9fbfc, white sheet #ffffff, ink #131416, secondary #5d5f60, teal #1b6c80, pale work surface #f4f6f8. One primary near-black action. Compact controls and no resting shadows.

The face is a cool, very lightly tinted frame, a custom transfer mark, and the literal “Anytype → Anchor” route at the top of the workspace. The signature is a real note preview beside conversion controls: toggling tags changes what the selected note will carry to Anchor.

Layout: a compact header above an inset white sheet. The left column holds source and options; the wider right column holds the selected objects and note preview. On phones the source and options precede the review, and every action remains available. The builder pattern's graph is replaced with a note list and preview because this product transforms documents rather than editing a graph; the two-panel composition and sheet geometry remain.

Content: Convert an export; Anytype export; What to bring; Review your notes; Download Anchor ZIP; How to export; Import into Anchor. No illustrations or third-party media are required for the task.

Dark mode keeps the Framed sheet geometry and bundled type. Neutral surfaces #111111 / #171719 / #202022 replace the light fields; #f3f3f3 ink, #b4b4b4 secondary text, and a lighter teal #7cc6d6 retain hierarchy. The primary action inverts to a pale fill with dark text. The sun/moon control is 44×44px, keyboard accessible, follows the device by default, and remembers an explicit preference. Only this preference is stored; exported notes and files are never saved. No layout or type redraw.
