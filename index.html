    From Anytype to Anchor

    Export from Anytype

    1. Open your Notes or Tasks Set. Select the objects you want to move, then choose Export.
    2. Choose Any-Block → JSON for the most detail. Markdown also works. Binary Protobuf isn’t supported.
    3. Enable Include files and Include linked objects to bring media and tag names. Choose ZIP archive.

    A Set is a query, not a folder. Export the objects inside it; exporting only the Set definition won’t include its notes.

    Review and download

    Choose the ZIP here, adjust your options, and review the notes. Tasks become notes with a checked or unchecked first line. Tags in the body text are always kept; the tag switch controls tag properties.

    Import into Anchor

    Open Anchor → Settings → Import / Export → Import notes. Choose the downloaded ZIP and Anchor backup if asked. Review and confirm the import. Keep Skip existing enabled to avoid duplicates.

    Use a version of Anchor that supports Anchor backup imports. The ZIP also includes readable Markdown copies; import the ZIP once to avoid duplicates.

    What may change

    Images and supported audio import as attachments, shown separately from note text. Other file types are kept in unsupported-attachments/. Tables become text. Set filters, relationships, reminders, sharing, and history aren’t recreated. Missing dates use the conversion time. Any other conversion notes appear before download and in the report.
